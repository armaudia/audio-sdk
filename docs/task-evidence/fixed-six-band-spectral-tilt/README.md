# SDK-FIXED-SIX-BAND-SPECTRAL-TILT evidence package

Task-local, optional reference provider and deterministic synthetic DSP evidence
for a fixed six-band spectral tilt. Pinned SDK base:
`dc6b8ecb5c7fa0a6a00072ddf9c6a2e168b68acc`.

## Scope

- All task files are under `docs/task-evidence/fixed-six-band-spectral-tilt/`.
  No shared CMake file, contract, descriptor catalog, default, public API/ABI,
  installed v0 behavior, board, handoff, ruleset, other branch, PR or `main`
  was changed.
- The provider id is `sixband.tilt.reference.v0`. It is unregistered by default;
  a caller must link the task-local source and register it on its own registry.
- Delivery is a task-local CMake consumer with `AS_ENABLE_SIXBAND_PROVIDER=OFF`
  by default. The installed SDK remains unchanged: 16 kHz mono float32,
  160 samples per frame.
- Descriptor: `execution_modes:[2]`, `required_assets:[]`, no settings. An
  unexpected asset or nonempty settings is rejected.
- Algorithm: fixed gains `[-3.0, -1.5, 0.0, 1.5, 3.0, 4.0]` dB, interior edges
  `250, 500, 1000, 2000, 4000` Hz mapped to 256-point FFT bins
  `4, 8, 16, 32, 64`. A causal 256-point sqrt-Hann WOLA / 160-sample hop
  implementation applies the source-study bin gains and uses a smoothed
  (160 ms average / 80 ms correction) power follower.

## Evidence

`evidence/report.json` is the machine-readable report;
`evidence/REPORT.md` is the human-readable summary. It contains:

- Six-band two-tone sweeps with a 750 Hz anchor in the 0 dB band and measured
  stepped gains versus fixed targets.
- Impulse/step response, reported block-stamped buffering delay, startup and
  final padding, output peaks/headroom, silence/tiny/level-step numerical and
  state controls.
- Clean-speech-like, masker-like, near-clip and pre-clipped stimuli, plus a
  tilt → tanh(3x) → tilt interacting-nonlinearity case.
- A receiver-side masking fixture with the masker added after target processing
  at −5, 0 and +5 dB target-to-masker RMS ratio, compared against identity,
  tilt, an energy-matched scalar-only gain control, and a deliberate +1 dB
  level-confound control.
- Registration, duplicate-registration, descriptor/schema/digest, mode, asset,
  shape, nonfinite, epoch, reset, drain, partial-frame, interleaving and
  isolated-registry controls from the task-local CTest.
- Missing-input/missing-reference handling: no missing result scores as a pass
  or qualifies the candidate.

All fixtures are deterministic synthetic float32 files generated by
`tools/generate_fixtures.py`; fixture bytes are pinned by
`fixtures/FIXTURES.sha256`. Provider and tool sources are pinned by
`SOURCES.sha256`. External reference files and public boundary headers are
pinned in `report.json`.

The receiver-side numbers are band-energy redistribution measurements only.
They are not STOI/ESTOI, intelligibility, MOS or listening-benefit scores, and
no real listening panel or licensed runtime was used.

## Blockers and limitations

- The source study's whole-clip FFT energy restoration is noncausal. This
  provider uses a causal smoothed power follower; exact clip energy equality is
  applied only in the evaluator's energy-matched control.
- Unity-peak exceedances from energy restoration are recorded as a headroom
  risk. No limiter, DRC or release configuration is qualified.
- No listening panel, real-speech STOI/ESTOI, held-out benchmark, target-device
  timing/CPU/deadline/memory, model weights, downloads or release qualification
  were measured.
- Synthetic evidence is complete, but release qualification is false.

## Reproduction

Run from the SDK worktree root. Use a fresh temporary directory.

```sh
TMP=$(mktemp -d "${TMPDIR:-/tmp}/sixband-sdk.XXXXXX")
cmake -S . -B "$TMP/sdk-build" -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_LIBDIR=lib -DAS_BUILD_TESTS=ON \
  -DAS_BUILD_CONFORMANCE=OFF -DAS_BUILD_EXAMPLES=OFF
cmake --build "$TMP/sdk-build" --parallel 4
ctest --test-dir "$TMP/sdk-build" --output-on-failure
cmake --install "$TMP/sdk-build" --prefix "$TMP/prefix"

TASK=docs/task-evidence/fixed-six-band-spectral-tilt
python3 "$TASK/tools/generate_fixtures.py"

cmake -S "$TASK/provider" -B "$TMP/consumer-off" \
  -DCMAKE_PREFIX_PATH="$TMP/prefix" -DAS_ENABLE_SIXBAND_PROVIDER=OFF
cmake --build "$TMP/consumer-off" --parallel 4
ctest --test-dir "$TMP/consumer-off" --output-on-failure

cmake -S "$TASK/provider" -B "$TMP/consumer-on" \
  -DCMAKE_PREFIX_PATH="$TMP/prefix" -DAS_ENABLE_SIXBAND_PROVIDER=ON
cmake --build "$TMP/consumer-on" --parallel 4
ctest --test-dir "$TMP/consumer-on" --output-on-failure

python3 "$TASK/tools/evaluate.py" \
  --cli "$TMP/consumer-on/sixband_cli" \
  --work "$TMP/eval" \
  --sources-sha "$TASK/SOURCES.sha256" \
  --fixture-manifest "$TASK/fixtures/FIXTURES.sha256" \
  --build-info "$TMP/prefix/share/audio-sdk/build-info.json" \
  --controls-ok true

python3 "$TASK/tools/verify.py" \
  --cli "$TMP/consumer-on/sixband_cli" \
  --work "$TMP/eval" \
  --build-info "$TMP/prefix/share/audio-sdk/build-info.json" \
  --controls-ok true
```

`verify.py` checks all pinned digests and confirms that report regeneration is
byte-identical. Source pins are generated with:

```sh
find "$TASK/provider" "$TASK/tools" -type f | sort | xargs shasum -a 256 > "$TASK/SOURCES.sha256"
```
