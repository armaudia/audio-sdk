# SDK-ADAPTIVE-FEEDBACK-NOTCH — optional adaptive feedback notch reference

Task-local, synthetic/model-free DSP evidence for adaptive feedback notch
control on the public v0 provider boundary. This is **reference evidence only**:
the installed SDK, its ABI, descriptors, registry, defaults and frozen v0
behaviour are unchanged. No real audio, model, device, CPU/latency or release
qualification is claimed.

## Scope and boundary

- Fixed v0 format only: 16 kHz, mono `f32`, 160 samples/frame.
- Python reference: `fixture.py` (deterministic detector/notch/gain-margin
  simulation and metric generation).
- C reference: `provider/` (optional, unregistered provider source plus an
  opt-in CMake consumer test). It uses only `audio_sdk/provider_v0.h` and
  `audio_sdk/session_v0.h`; it is not built, registered or linked by default.
- Write scope is limited to this directory. No shared SDK file was modified.

## DSP evidence summary (synthetic)

All material is generated by seeded LCG/noise and analytic tones/sweeps; no
recordings are read. Values below are from `report.json`.

- Sweep 200–4000 Hz in 100 Hz steps: 39/39 frequencies activated; per-frequency
  steady-state gain 0.003–0.124; output digest
  `1f1d4df671abb4811a54d88360836f3d535906729819305bde3626dc3d7288c0`.
- Impulse: peak at sample 0 (no added delay), peak magnitude 0.5.
- Step: crossing 0 samples after onset, peak magnitude 0.25.
- Silence: no activation, peak output 0.0.
- Attack/release on a 1 kHz burst (frames 20–119): activation at frame 23
  (3 frames), release at frame 143 (23 frames after end); transitions
  `idle->active@23:1000`, `active->idle@143:1000`.
- Clean synthetic speech (300 frames): 0 false activations (0.0/minute),
  0 gain-margin activations. A tonal-vowel stress case with a sustained 1 kHz
  harmonic: 3 false activations (6.0/minute), 191 active frames — the
  false-trigger risk is reproduced explicitly rather than hidden.
- 1 kHz tone injected into speech (frames 100–199, amplitude 0.035):
  1 activation in the tone region, 0 in the clean region, tone power reduced
  12.693 dB (−26.408 → −39.101 dB); clean-region tone metrics unchanged.
- Closed loop with one-frame feedback delay and a 1 kHz resonator at loop
  gains 1.05/1.15/1.3: identity grows (tail +30.9 to +31.5 dB relative to
  program); fixed −5 dB margin stays stable (tail −57.5 to −208.6 dB, zero
  rejected frames); notch+saturation stays finite and bounded (tail
  −551 to −568 dB, peak < 0.8, zero rejected/nonfinite frames). Notch-only and
  notch+margin behave differently by gain and still reject clipped frames —
  adaptive notch alone is not shown as a stable standalone control.
- Invalid/nonfinite/short frames are rejected with state unchanged; missing,
  malformed, nonfinite and out-of-range controls fail explicitly.

## Adverse cases, skips and explicit non-claims

- Rejected controls: `None` config, missing key, nonfinite (`nan`/`inf`),
  out-of-range (`q=1.0`), wrong type, unknown key; rejected frames:
  nonfinite sample, out-of-range sample, short frame. All leave state unchanged.
- Unsupported execution modes (`INLINE_CALLBACK`, `BUFFERED_WORKER`) and
  missing effective config bytes fail before any session state is returned in
  the optional C check.
- No real speech/music, measured loudspeaker/microphone path, device run,
  license/rights intake, production CPU/latency measurement, or release
  approval is included. The C provider is intentionally not installed,
  registered by default or added to any catalog.
- The mutable board digest is a snapshot only; board changes do not qualify or
  disqualify this evidence.

## Reopen / release gates

Reopen before any default or production claim:

1. Closed-loop measured loudspeaker/microphone evidence with pinned paths,
   gain-before-feedback, delay and nonlinear saturation.
2. Held-out real speech/music false-trigger and intelligibility/quality tests.
3. Maximum stable gain, residual tone, attack/release, clipping, CPU/memory and
   target-device timing on the intended runtime.
4. Provider intake, rights/license, descriptor and public catalog review.

Until those gates pass, this directory remains optional task-local reference
evidence and the installed v0 behaviour stays frozen.
