## Caller-supplied-artifact contract

A caller manifest is accepted only when it has exactly the declared 31 fields,
every file path is absolute and present, every directory path is absolute and
present, every declared SHA-256 matches, the runtime version has a semver
shape, the entitlement ID and platform are lowercase tokens, geometry is
declared 16 kHz / mono / `f32`, `scope=denoise_only_offline_comparison`,
`variant=offline_whole_utterance` and `processing_stage_scope=denoise_only`.
Streaming, normalization, loudness-control and voice-processing scopes are
rejected here; they are separate future gates.

Validation hashes the caller's files but never imports, links or executes the
vendor SDK, never reads a model weight and never invokes a scorer. Structural
acceptance deliberately returns `accepted_for_qualification=false`,
`vendor_runtime_approved=false`, `asset_license_approved=false` and
`qualification_effect=none`, because no vendor runtime, component licence or
parity vector has been approved.

Because no exact vendor runtime version is published in the merged evidence,
the contract sets `required_vendor_runtime_version=null` and
`runtime_version_pin_available=false`. The validator enforces the version shape
but cannot compare it to a known pin; the runtime-identity gate remains blocked
until an exact approved version is supplied.

## Reproduction

Use the pinned interpreter with bytecode writing disabled. From this directory:

```sh
PYTHONDONTWRITEBYTECODE=1 /Users/htsakanyan/.pyenv/versions/3.12.16/bin/python3.12 run.py all
PYTHONDONTWRITEBYTECODE=1 /Users/htsakanyan/.pyenv/versions/3.12.16/bin/python3.12 -m unittest -v test_reference.py
PYTHONDONTWRITEBYTECODE=1 /Users/htsakanyan/.pyenv/versions/3.12.16/bin/python3.12 verify.py
python3 -m reuse lint
git diff --check
```

`run.py all` performs three cold writes and requires all four artifacts to be
byte-identical. `verify.py` re-runs three independent cold-start regenerations
in scratch trees and fails on any pin drift, out-of-scope change, missing
sidecar, missing SPDX header or absent blocker. It also gates the branch diff
against the pinned base so committed out-of-scope files cannot pass.
