# SDK-WEBRTC-APM-NS — task-local synthetic noise-suppression evidence

**Decision: `proposal_only_not_qualified` / `incomplete` / `DEFER`.** This is a
self-contained, deterministic, fully synthetic evidence package. It does **not**
contain, download, install or wrap the WebRTC APM runtime, a wheel, a binary,
weights or any licensed asset. It makes no authoritative WebRTC NS result,
oracle, listening, quality-acceptance or release claim.

## Exact scope and boundary

- Installed v0 behavior stays 16 kHz mono `float32`, 160 samples per frame.
- `reference.py` implements a synthetic decision-directed Wiener-style
  suppressor with level floors, a classical spectral-subtraction baseline and
  bit-exact identity/noisy controls. All clean references are generated by
  `fixture.py`; no recording or corpus is read.
- `scorer.py` is dependency-free: zero-mean SI-SDR and a deterministic
  **STOI-style proxy** (`synthetic-stoi-style.v1`). It is not pystoi, extended
  STOI, an audio-bench scorer, a MOS prediction or a listening test.
- `run.py` is a protocol-v1-shaped, opt-in, unregistered developer adapter plus
  canonical report regeneration. It is not an SDK provider and is never
  registered, default-enabled or linked.
- No C boundary, shared CMake, CI, contract, public API, ABI, header,
  descriptor default, provider registration, installed v0 behavior, board,
  handoff, ruleset or main change is included.
- Alignment, state, memory and content/availability timing are analytic or
  frame-index labels. They are explicitly **unpaced/synthetic**, not
  target-device measured CPU, memory, content delay or deadline results.

## Enhancement-profile application

| Required element | How it is applied |
| --- | --- |
| Identity / noisy control | `noisy_identity` is bit-exact to the noisy input; a generated clean input is also passed through every variant for preservation. |
| Established task-matched baseline | `spectral_subtraction` (oversubtraction 2.0), explicitly separate from the synthetic candidate. |
| Paired scoring | SI-SDR and STOI-style proxy on generated clean references for two SNR conditions, every variant; deltas are relative to the paired noisy input. |
| Clean-speech preservation | Clean input scores, peaks and finite checks are reported per variant; SI-SDR at exact identity is explicitly undefined, not a claimed infinite score. |
| Peaks / invalid outputs | All peaks are below clipping; nonfinite input/output, wrong shape/type/range, stale epoch/position, unknown variant, closed session and invalid config are explicit rejections. |
| Unpaired speech | `unpaired_predictive_screen` is a separately labeled predictive proxy only; no clean reference, no MOS/STOI claim, no human listening, no qualification. |
| Alignment / state / memory / timing | Frame-index zero added delay, impulse index, independent state configurations, reset replay, analytic retained-float count; all labeled unpaced synthetic, device measurement `false`. |
| Missing results | `blocked`/`unscored` with `metrics: null`; `missing_result_qualifies: false`. |
| Adverse results | Negative or non-positive paired deltas are retained in `adverse_results`; they do not qualify any variant and are never hidden. |

No gate is weakened: all five release gates remain `not_met` and the decision
is `DEFER` regardless of the synthetic scores.

## Reproduction

Run from this directory on the pinned worktree:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest -v test_reference.py
python3 run.py --report
python3 run.py --sources
python3 verify.py
python3 check_licensing.py
```

`run.py --report` regenerates `report.json` plus `report.json.sha256`
byte-identically; `run.py --sources` prints the exact `SOURCES.sha256` manifest.
`verify.py` separately checks strict JSON, source pins, manifest, canonical
bytes, three cold-start report regenerations, scope invariants, paired results
and licensing. JSON is canonical (`sort_keys=True`, compact separators,
`allow_nan=False`) with one trailing newline.

Baseline SDK verification was run outside the worktree at the rebased head:
CMake configure/build/install, `ctest` 11/11, read-only swarm `check.py`,
`git diff --check`, `git diff --cached --check` and REUSE 6.3.0 lint (no
violations in this task-local package).

## Failure controls and explicit non-claims

- `report.json` includes a bundled representative valid result, a missing case
  that is `blocked` with `metrics: null`, an invalid-samples rejection and a
  bit-exact identity control.
- No numpy, scipy, pystoi, torch, download, WAV, checkpoint, model file,
  licensed runtime, real speech, device timing, listening test or release
  claim is used. `check_licensing.py` verifies dependency and SPDX boundaries.
- Historical pilot figures from the source evidence are reported as source
  statements only; none is reproduced or used as a threshold here.
