# Licenses and boundaries

This task-local evidence package is authored for SDK-TD-PSOLA and licensed under
Apache-2.0 per file SPDX headers/sidecars.

## Scope

- No TD-PSOLA, Praat, Parselmouth, or third-party source/runtime/assets are
  vendored, mirrored, downloaded, or executed.
- No real audio, corpus, model weights, candidate output, or listening material
  is included.
- Pinned external research/plan files are referenced by path and SHA-256 only;
  their original licenses/terms remain with their upstream owners.
- Sibling evidence files (`psola-praat`, `diffatsm`) are read-only boundary
  pins and remain under their own repository licenses.

## Reopen condition

Any future artifact intake must provide reviewed license/notice records,
rights-cleared inputs, immutable revisions, and independent review before any
qualification or release claim.
