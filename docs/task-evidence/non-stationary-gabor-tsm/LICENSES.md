## Upstream declarations, not staged licences

The pinned research note names Prusa and Holighaus, "Phase vocoder done
right", EUSIPCO 2017, and records that reference implementations may be
copyleft (LTFAT is GPL-3.0) and should be treated as papers, not vendored
code. No LTFAT licence text, `COPYING`, `NOTICE`, source file, wheel or binary
is copied, downloaded, verified or redistributed. The paper DOI is
source-reported context only.

## Required rights review before implementation

- Exact reference code licence text, `COPYING`/`NOTICE`, README and any
  third-party notices at an immutable revision.
- An explicit decision on GPL-3.0 isolation, process separation, dynamic
  linking, distribution and derived-output terms if LTFAT is used.
- A permissive alternative reference and its complete licence provenance if
  LTFAT cannot be used.
- FFT, numeric and packaging dependency licences with exact hashes.
- Rights-cleared speech and music inputs with consent, acquisition,
  evaluation, derived-output and redistribution decisions.
- Attribution and notice bundle for any redistributed derived output.
