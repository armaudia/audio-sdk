## Proposed feasibility: SDK-OBS-01-SPLICE-STEP-FEASIBILITY

**Proposed, unassigned, not a board entry.** Parent: `SDK-SURVEY-OBS-01`; suggested dependencies: `SDK-FND-AUDIT`, `SDK-FND-EVIDENCE`. Consult `SDK-PIPE-CAPTURE`, `SDK-MEDIAN-RESIDUAL-CLICK-GATE` and `BENCH-FND-CHECK` before dispatch. The audited inventory and board scopes cover level/clip metrics, repair and chain validity, but no dedicated component owns an offline measurement of a waveform step at a *declared* boundary. This is one narrow, asset-free use of S46's discontinuity lead; it is not a SIG Challenge reproduction, a blind click detector or a waveform repair.

- **Smallest reproducible check (not run):** use authored mono 16 kHz float literals `[1, 0, 0, 0, 0, -1]` (identity) and `[1, 0, 0, 0.5, 0.5, -1]` (planted step); valid interval `[1,5)`, zero-based boundary `b=3`. Compute `abs(x[b] - x[b-1])` only when both endpoints are finite and valid in the same continuous source span. Expect `0` and `0.5` respectively. Split the planted case at sample 3 into two adjacent valid delivery blocks of the same span; result must stay `0.5`, not be lost or counted twice.
- **Failure controls:** boundary `b=5` on the planted case must produce no value (padding); declare sample 2 missing for the cross-block case and require no value (no bridging a gap); replace sample 3 with `NaN` and require an invalid/nonfinite row. Keep all six attempted rows (three measured, three with no value) and a distinct reason per unmeasured row. Do not refit intervals or treat missing as zero.
- **Deliverable:** a task-local replay and metadata report with frozen fixture/digest, zero-based boundary and valid spans, counts, reason codes and deterministic rerun equality. Require the exact outcomes above and read-only samples; no model, speech media, scorer rerun, new SDK ABI or routing hook. Stop at feasibility. Any later advisory tap goes through `SDK-FND-ANALYSIS` with source timestamp, availability and staleness checks; natural defect accuracy needs separately permitted annotated positives/negatives and an independent holdout.
