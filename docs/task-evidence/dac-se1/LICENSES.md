# Licensing boundary

This task-local evidence package is licensed under Apache-2.0. It contains no
third-party source, checkpoint, tokenizer, vocoder, weight, model card, license
text, notice, audio, corpus or manifest payload bytes.

## Upstream declarations, not staged licenses

The census records that the official ETH-DISCO/DAC-SE1 code and the Hugging Face
`disco-eth/DAC-SE1` checkpoint both **declare MIT**. This package does not copy,
download, verify or redistribute either license text or artifact. The
declaration is source-reported context only.

## Required rights review before implementation

- Code license text, `COPYING`/`NOTICE`, model card and any third-party notices
  at an immutable revision.
- Weight-specific terms, model-card terms and training-data statement.
- Codec/tokenizer/vocoder lineage and terms, including any derived model files.
- Rights-cleared caller inputs with acquisition, evaluation, derived-output and
  redistribution decisions.
- Attribution and notice bundle for any redistributed derived output.

## Boundary

No vendored third-party bytes. No provider, descriptor, registry, installed
default, public ABI, shared build or CI change. No release claim.
