on the text and Python artifacts and `.license` sidecars for the JSON, digest
and manifest files). It contains no Moonshine source, model weight, ONNX graph,
tokenizer, runtime binary, audio, transcript, corpus, model card, license text
or notice. Files outside the package are pinned by SHA-256 only.
