# Licensing and provenance

This evidence package is licensed under **Apache-2.0** (SPDX headers on text and
Python artifacts and `.license` sidecars for JSON/digest files). It adds no
provider, model, runtime, corpus, or license grant.

## Upstream SE-AGCNet material

No SE-AGCNet source checkout, model checkpoint, pretrained weights, runtime,
license text, NOTICE, or third-party notice bundle is present in this workspace.
Research references the upstream repository and project page, but no immutable
revision, file digest, reviewed license identity, or runnable artifact was
verified locally. No upstream file is copied into this package.

## Evidence inputs and boundaries

Read-only source and boundary inputs are pinned by SHA-256 in `SOURCES.sha256`
and the README digest tables. They are not copied into this package. The mutable
swarm board is never hashed; only the stable linked-row projection is gated.

## Scope

This package contains only deterministic text, JSON, and Python source under
`docs/task-evidence/se-agcnet/`. It contains no model, audio, recording, corpus,
binary library, compiled object, or vendored upstream artifact.
