# NVIDIA Background Noise Removal v2.1 — vendor boundary evidence

This package records an **external-adapter feasibility investigation** for task
`SDK-NVIDIA-BACKGROUND-NOISE-REMOVAL-V2-1`. It is proposal evidence only. No
NVIDIA artifact, model bundle, entitled runtime, license text, rights decision,
matched cohort or candidate output is present, opened, loaded or fabricated.
The decision is `DEFER` and the qualification is `not_qualified`.

## Evidence and blockers

The pinned census records NVIDIA BNR v2.1 as a commercial call-focused CRNN
with source-reported scores. Those scores are provenance only; none is
reproduced or attributed to this package. Exact blockers remain: immutable
artifact and weights with byte count and SHA-256; exact NVIDIA Open Model
License terms and written commercial/output-use decision; an entitled
Audio Effects 2.1 / CUDA / TensorRT / driver stack with supported GPU and lock
digest; verified 16/48 kHz geometry including state, lookahead and delay; and a
rights-cleared paired clean/noisy cohort with a pinned scorer. Eight release
gates are blocked.

The mutable full `plan/swarm/TASKS.json` is never hashed. Only a stable
linked-row projection (task id, title, mode, repository, component) is pinned.
No provider registration, descriptor default, public API/ABI, installed-v0
behavior, shared build or CI change is made.

## Reproduction

From this directory, with Python 3.11 or newer:

```sh
python3 -m unittest -v test_reference.py
python3 run.py --all
python3 run.py --verify-repro
python3 verify.py
python3 -m reuse lint
```

`run.py --all` regenerates `report.json`, `report.json.sha256`,
`SOURCES.sha256` and `contract.json` three times and requires byte-identical
repeats. `verify.py` performs three additional cold-start report checks and
compares every committed artifact with its generated bytes.
