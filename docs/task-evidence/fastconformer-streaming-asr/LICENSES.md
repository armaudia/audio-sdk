# Licensing

This task-local evidence package is first-party work released under
Apache-2.0. It contains no upstream FastConformer, Conformer-TED, NeMo,
PyTorch, CUDA, tokenizer, checkpoint, weight, corpus or audio bytes. No
upstream license text, notice or model card is vendored here; the package only
records the exact missing artifact and rights requirements.

The shared SDK license text is at `LICENSES/Apache-2.0.txt` and the aggregate
`docs/**` annotation is in `REUSE.toml`. Every generated JSON artifact has a
REUSE sidecar in this directory.
