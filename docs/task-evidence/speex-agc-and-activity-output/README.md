# SDK-SPEEX-AGC-AND-ACTIVITY-OUTPUT — task-local Speex AGC + advisory activity evidence

A **deterministic, synthetic, opt-in developer reference**, not a product AGC,
VAD, quality improvement, device result, listening result, pacing result or
release claim. It uses **one** Speex preprocessor per stream with AGC and VAD
enabled together, keeps the activity output **advisory**, and records the exact
combined configuration behavior against the pinned DSP acceptance profile.
Nothing is registered, defaulted, published or copied into a public benchmark.

## Scope and isolation

- Sole write scope: `docs/task-evidence/speex-agc-and-activity-output/`.
- No public API, ABI, descriptor, registry, default provider, installed
  `speex.ns.v0` behavior, shared CMake file, CI workflow or other worktree is
  changed.
- `adapter/CMakeLists.txt` is a standalone project. Its only new option,
  `AS_ENABLE_SPEEX_AGC_ACTIVITY_REFERENCE`, defaults **OFF**. The target is not
  built, installed or registered unless a caller explicitly opts in. With the
  option off, the configure step produces no executable.
- All stimuli are generated by stdlib Python arithmetic; all native builds,
  raw f32 files, per-run metadata and temporary outputs stay in private
  scratch directories outside the worktree. No corpus, model, weights,
  download, real speech, audio asset, licensed runtime or listening result is
  included.
- Base commit: `941cabfc39f7e33f01881b6e50e3a1e49e7eb9ce`.
  Parent observed before the commit: `56d9781b984aa493e5c56e0479a20c746351102e`.
  Branch: `swarm/SDK-SPEEX-AGC-AND-ACTIVITY-OUTPUT`.

## What is measured

The native adapter calls only the public `speex/speex_preprocess.h` boundary.
It compiles the exact vendored SpeexDSP sources pinned in `SOURCES.sha256`
(20 source/policy pins, all `match`). One `SpeexPreprocessState` is initialized
at 16 kHz with 160-sample frames.

- AGC: `SPEEX_PREPROCESS_SET_AGC=1` in a `FLOATING_POINT` build, with pinned
  target level, increment, decrement and max gain.
- Activity: `speex_preprocess_run()` return value plus `GET_PROB` and
  `GET_AGC_LOUDNESS` metadata. The VAD flag changes only the advisory return
  value; it never gates, suppresses or reroutes audio. The gain trajectory with
  `combined` is byte-for-byte the trajectory with `agc_only`.
- Audio path: float → PCM16 clamp/`lrintf(FE_TONEAREST)` → one preprocessor →
  float/32768. Denoise and dereverb are OFF by default; `combined_denoise` is
  an explicitly interacting-nonlinear control.
- Pinned comparison set: 23 cases × 3 repeats, each repeat byte-identical for
  both f32 output and per-frame metadata. There are no tolerances, no provider
  substitution and no widened acceptance.

## DSP acceptance profile coverage

The profile text is pinned from `plan/swarm/VERIFICATION.md`
(`3f2631333e4436a6441236a2b21f4d5b45fb3bb3619f600767e22eb957f77910`) and
applied as follows:

| Profile element | Evidence in `evidence/report.json` |
| --- | --- |
| sweeps | `combined_chirp` (200–4000 Hz amplitude ramp), `combined_gain_step` |
| steps | `combined_steps`, `fast_steps`, `reset_steps` (silence→quiet→loud→quiet) |
| impulses | `combined_impulse`, `identity_impulse` (sample 400) |
| silence | `combined_silence`, `identity_silence` |
| clean speech | `combined_speech_like`, `identity_speech_like` (band-limited voiced surrogate) |
| intelligibility/load control | `speech_like` burst envelope; `noise_only` LCG non-speech control |
| gain | `agc_gain_db_min/max/sequence` per frame |
| response | chirp/step output metrics, impulse peak location |
| attack/release | step cases, fast-config case, reset case |
| headroom | `peak_abs`, `clipped_or_at_one` on every case |
| delay | impulse peak measured at 560 for both identity and combined; 160 samples (10 ms) of shared preprocessor lookahead are recorded, with no separate gain-delay assertion |
| numerical behavior | fail-closed nonfinite control plus finite-output checks |
| state transitions | reset at frame 10, silence→burst sequences, loud→quiet steps |
| interacting nonlinear configurations | combined AGC+VAD, `combined_denoise`, prob-threshold variants, target-level variants |

Representative frozen results (all from synthetic stimuli):

- `combined_speech_like`: AGC gain −7…5 dB, 93/100 advisory-active frames,
  peak 0.435272, RMS 0.073343.
- `combined_steps`: gain −7…17 dB, 70/100 active frames, peak 0.855560.
- `combined_chirp`: gain −2…30 dB, peak 0.876282, no clipping to 1.0.
- `combined_silence`: gain 0 dB throughout, zero activity, zero output.
- `vad_only` gain is identically 0; `agc_only` and `combined` gains are equal.
- `prob_60_40` reduces advisory-active frames from 93 to 89 without changing
  the AGC gain trajectory.

## Failure and control results

- Fail-closed numerical control: a stimulus containing NaN at sample 5 and
  +Inf at sample 165 is rejected with exit code 3 and
  `ERROR 3 samples nonfinite or outside [-1, 1]`; no output is produced.
- Identity-feature control: with AGC, VAD and denoise off the preprocessor
  still shows the same 160-sample lookahead. This is reported as "identity of
  feature flags", explicitly **not** bit-exact passthrough.
- Missing-render/echo or provider-substitution analogs are not applicable:
  this fixture has no paired reference path and no alternative provider.
- Read-only `plan/swarm/check.py --task SDK-SPEEX-AGC-AND-ACTIVITY-OUTPUT`
  exits 0; its stdout digest is recorded in the report.

## Reproduction

From the worktree root:

```sh
python3 docs/task-evidence/speex-agc-and-activity-output/run.py --validate
python3 docs/task-evidence/speex-agc-and-activity-output/run.py --report
python3 -m unittest discover -s docs/task-evidence/speex-agc-and-activity-output -p 'test_*.py'
```

`--report` rebuilds from the pinned sources into private scratch space and
requires a byte-identical match with the canonical report. The report contains
no live git state, timestamp or test duration, so it is stable across the
single DCO commit.
