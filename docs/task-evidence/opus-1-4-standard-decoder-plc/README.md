## Boundary model and algorithm

The shipped public v0 facade has no frame-level "packet lost" input flag:
`as_frame_v0.flags` only admits `AS_FRAME_FINAL_INPUT`, and
`AS_RESULT_CONCEALMENT = 4` is a *result* flag. This fixture therefore models
the **host delivery-adapter boundary**: one call per 160-sample source frame,
a missing packet as `present=False, valid_count=0`, and concealed output slots
carrying flag `4` with `valid_count = 0`. Per `CONTRACTS.md`, adapter
concealment is **not a produced provider frame and cannot satisfy sample
conservation**; valid content is conserved by the good frames alone.

Conditions on the identical frozen erasure mask:

| Condition | Role | Behaviour |
| --- | --- | --- |
| `identity_clean` | identity control | no erasure; bit-exact clean delivery |
| `zero_fill_baseline` | degraded/noisy control and simplest task-matched baseline | erased slots are all zero |
| `hold_control` | additional waveform control | repeat last received sample |
| `linear_control` | established task-matched baseline (pinned candidate matrix row 29/30) | ramp from last good sample to first sample of next good frame |
| `plc_reference_candidate` | synthetic decoder-PLC-style candidate | causal pitch-period repetition from the last good frame with fixed progressive amplitude decay |

The candidate estimates a pitch lag by normalized autocorrelation over
40–159 samples of the last good frame (smallest-lag tie-break, minimum
correlation 0.20), repeats that excitation segment cyclically for the erased
frame, and attenuates by a fixed gain per burst frame: `0.92, 0.76, 0.55,
0.32`. With no good history or at drain it uses an explicit zero-fill/
hold fallback. It has **0 intrinsic algorithmic delay** and uses only past
context. The gains and estimator are a deterministic synthetic recipe, **not**
codec parameters.

The 800-sample (5-frame) output buffer is an explicit host scheduling choice
that keeps source slots one-to-one with output frames. A 4-frame maximum burst
and 8-call drain cap are enforced. Frame admission rejects missing/short/
wrong-shape/zero-length/nonfinite/bad-padding frames, stale epochs,
duplicates, out-of-order and future packets, frames after final, and
over-length bursts without changing stream state. Reset, epoch, close and
session isolation are exercised.
