# SDK-FFMPEG-AFWTDN — task-local synthetic Enhancement evidence

Proposal-only, incomplete and **not qualified** (`decision=DEFER`). This package
is a deterministic Python reference over frozen synthetic deterministic PCM. It
is optional, unregistered and OFF by default. It does not change the public
API/ABI, installed v0 behavior, descriptor settings, provider registry, defaults,
build, CI, board or handoffs. No real audio, model, FFmpeg runtime, device
timing, listening result, benchmark or release claim is made.

## Boundary and disposition

- Documented public v0 geometry only: 16 kHz, mono, float32, 160 samples/call,
  in exact 160-sample frames plus one partial final frame.
- `registered=false`, `enabled_by_default=false`, `default_selected=false`,
  `descriptor_settings={}`, `public_api_abi_change=false`,
  `processor_exposure=false`; see `provider.json` and `contract.json`.
- Evaluation fixture and any future production callback paths are distinct.
  No production callback is implemented or invoked.
- All release gates remain blocked. Missing evidence never qualifies the
  candidate; no source-reported or synthetic number is promoted to parity.

## Enhancement acceptance profile

Applied on synthetic deterministic PCM with frozen clean references:

- `identity` bypass control is bit-exact to the clean target; the perfect
  reconstruction SI-SDR is explicitly undefined and excluded.
- `noisy_control` supplies the named matched `noisy_input_no_processing`
  baseline; `low_snr`, `burst_noise` and `silence` cover edge conditions.
- Paired zero-mean SI-SDR and non-extended STOI come from a pinned,
  dependency-free scorer previously crosschecked against pystoi 0.4.1. The
  scorer port is copied verbatim from the pinned classical-wiener evidence and
  hashed in `SOURCES.sha256`.
- Clean-speech preservation, peaks, clipping and nonfinite counts, alignment,
  duration, partial final frame, reset replay, session isolation and silence
  are reported alongside the candidate. Losing conditions are recorded
  verbatim in `regressions`; none are hidden.
- Fail-closed config, frame, lifecycle and validity cases are actually
  exercised through `Controller`, not merely asserted. Nonfinite, wrong-shape,
  out-of-range, stale-epoch, stale-position, missing-sample, closed-session and
  finished-session cases are rejected; DSP state is unchanged by a rejected
  frame; unknown validity is never counted as nonspeech.
- Blocked: task-matched external baseline, exact runtime, content/availability
  timing, rights-qualified cohort, independent listening, provider intake,
  public default and exact reference parity.

## FFmpeg 7.1 / GPL provenance gap (explicit blocker)

`tool-provenance.json` records the historical `FFmpeg 7.1 afwtdn` candidate and
`GPL-2.0-or-later` provenance from the pinned asset ledger. The exact build
string and configure flags are **not** available locally and are not invented.
No FFmpeg binary, source, download, vendored artifact, wrapper or licensed
runtime is included, resolved or invoked. No FFmpeg process is started, no WAV
is generated by FFmpeg and **no numeric parity with FFmpeg is claimed**. The
pinned pilot's source-reported negative quality changes are context only and
are not reproduced, imported or pooled here.

## Files

- `reference.py` — deterministic generator, fail-closed controller and report builder.
- `scorer.py` — verbatim pinned dependency-free SI-SDR/STOI port.
- `run.py` — regenerates `report.json`, `report.json.sha256`, `contract.json` and
  `SOURCES.sha256` byte-for-byte.
- `report.json` / `report.json.sha256` — canonical evidence and digest.
- `SOURCES.sha256` — strict SHA-256 manifest for external, boundary and all
  local task files (never pins itself).
- `contract.json`, `provider.json`, `tool-provenance.json` — machine-readable
  scope, unregistered/OFF disposition and blocked provenance.
- `report.json.license`, `report.json.sha256.license`, `SOURCES.sha256.license` —
  SPDX sidecars for generated files without embedded headers.
- `test_reference.py` — 40-test Python unittest suite.
- `check_licensing.py` — task-local SPDX, dependency-boundary and artifact check.
- `verify.py` — strict read-only pins/JSON/reproduction/licensing/scope verifier.
