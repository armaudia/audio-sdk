# S01 — source/provenance allocation and baseline

Status: complete for the initial two-provider scope; no release/legal
qualification is claimed.

## Evidence

- Read-only legacy source inspected under `../../cpp-library`.
- Copied only the inventoried `third_party/speexdsp/` tree (39 files), its
  upstream `UPSTREAM.md`, `COPYING` and `COPYING.kissfft`; exact file hashes
  are in `deps/speexdsp-files.sha256` and file-level allocation is in
  `docs/migration/source-allocation.csv`.
- No neural weights or other model assets were copied.
- Original library configured and built:

  ```sh
  cmake -S ../../cpp-library -B build/baseline-logs/build \
    -DCMAKE_BUILD_TYPE=Release -DAE_BUILD_TESTS=ON \
    -DAE_BUILD_BENCHMARKS=OFF -DAE_BUILD_EXAMPLES=OFF \
    -DAE_ENABLE_ONNXRUNTIME=OFF -DAE_COMPONENT_FASTENHANCER=OFF \
    -DAE_COMPONENT_SILERO_VAD=OFF
  cmake --build build/baseline-logs/build --parallel 2
  ```

  Both succeeded on macOS 27.2.1 arm64, Apple clang 21.0.0 and CMake 3.27.4.
- The timing probe was compiled with `-std=c11 -Wall -Wextra -Werror` against
  the original public header and locally built library. It measured identity
  0, legacy Speex 160 (declared 0), and high-pass 0. See
  `build/baseline-logs/legacy-timing-before.json`.
- Runtime evidence used Python 3.11.5, pytest 9.0.1 was available. CPython
  3.12, NumPy, and `jsonschema` are not installed.

## Limitations

This is a local macOS baseline only. Linux baseline, rights review, public
release approval, and legacy ABI migration are not asserted.
