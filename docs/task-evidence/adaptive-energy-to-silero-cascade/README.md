# SDK-ADAPTIVE-ENERGY-TO-SILERO-CASCADE — task-local evidence

**Status: proposal-only / synthetic; qualification `incomplete`.** This is a
minimal optional reference at the public adapter boundary for an
adaptive-energy gate followed by a stateful Silero-style second stage. The
Silero stage is a **MODEL-FREE STUB**: a smoothed analytic sigmoid on frame RMS.
No Silero weights, source revision, ONNX runtime, download, licensed asset or
real-model output is present or claimed.

The installed SDK, its public API/ABI, `CONTRACTS.md`, `CMakeLists.txt`,
descriptor registry, defaults and installed v0 behavior are unchanged. All
writes are inside `docs/task-evidence/adaptive-energy-to-silero-cascade/`.

Pinned base: `dc6b8ecb5c7fa0a6a00072ddf9c6a2e168b68acc`.
Optional task-local provider ID: `detection.adaptive-energy-to-silero-cascade.refv0`.
Required caller assets: none. External provider settings must be `{}`.

## Analysis contract

- Fixed v0 format only: 16 kHz, mono, float32, 160-sample frames, half-open
  int64 source intervals and a monotonic nanosecond availability clock.
- The historical adapters declare 320-sample energy and 512-sample Silero
  frames with 64 context samples. Those sizes are recorded as divergence; v0
  was not changed and numeric parity is not claimed.
- `fixture.py` generates 330 deterministic frames (52,800 samples) from a
  seeded LCG and analytic tones. The first 300 frames (48,000 samples) are
  scored; the last 30 frames have `validity: unknown` and are excluded.
- Segments cover idle noise, quiet speech, active speech, a low-level negative
  noise burst, transition silence and a known-positive synthetic
  cross-environment low-SNR speech stratum, plus the unknown tail.
- The v0-adapted `agreement_sleep`-style reference uses three agreeing
  low-energy frames to sleep, a 50-frame stub cross-check while asleep, a
  0.5 stub decision threshold, two-frame onset and three-frame offset. This
  is a structural reference, not the historical 20 ms policy or its numbers.
- Timestamped `gate_probability`, `stub_probability` (only when invoked) and
  `cascade_probability` events plus `speech_event` boundaries are emitted on
  the proposed analysis-event model. Analysis events are not v0 ABI.
