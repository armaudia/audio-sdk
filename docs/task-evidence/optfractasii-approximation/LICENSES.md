This directory contains task-local blocker evidence only. It vendors no
OptFractASII source, binary, weight, dataset, masker recording, speech corpus,
listener result, or runtime package.

| Boundary | Status | Notes |
| --- | --- | --- |
| Pinned research note | source-reported, read-only | `research/listening_intelligibility_20261028.md` is pinned by SHA-256 and quoted only as source-reported context; it is not promoted to a release-quality result. |
| Exact upstream OptFractASII artifact | absent | No exact immutable upstream source snapshot, license text, notice bundle, algorithm identifier, filterbank/importance table, or reproduction recipe is present locally. |
| Local approximation code | absent from this package | No local NELE/OptFractASII approximation implementation, audio asset, or output is copied into this evidence directory. |
| Rights-cleared evaluation cohort | absent | No rights-cleared target speech, masker corpus, consent record, hearing profile, or output-use permission is present. |
| Runtime / device evidence | absent | No pinned runtime, device timing, listening study, or benchmark claim is made. |
