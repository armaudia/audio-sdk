# Corresponding source

Each native package contains the corresponding source tree under
`share/audio-sdk/source/`, including covered modifications and the complete
MPL-2.0, Apache-2.0 and retained third-party notices. The machine-readable build
and release manifests identify the source revision and runtime input hashes.

Public source repository: https://github.com/armaudia/audio-sdk
Retrieve the exact source revision recorded in the package manifest. A working
copy with uncommitted changes is development evidence, not a clean release.
The source rights are not restricted by proprietary terms for separate products.
