# Security policy

Report vulnerabilities privately using [GitHub Security Advisories](https://github.com/armaudia/audio-sdk/security/advisories/new). Do not place secrets, private audio, model weights or exploit payloads in public issues.

Only the latest published version is considered for fixes. Until a supported release is published, the main branch is development software. Neither the SDK nor the benchmark collector is an isolation boundary for hostile native code. The benchmark public submission and publication gates remain closed.
