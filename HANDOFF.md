## Blockers, prerequisites and breaking changes

1. **Legacy compatibility:** original `ae_*` headers/layouts have now been
   located in the read-only `../cpp-library/include/audio_enhance/` source.
   The compatibility target is still absent; preserve the original library for
   all ABI 1.x consumers until a real adapter is built and tested.
2. **Linux package/CI:** no Linux x86-64 host/toolchain was available; package,
   system dependency, sanitizer and Linux conformance claims are unverified.
   The checked-in hosted CI workflow has not run.
3. **Reproducibility:** candidate 04 is immutable and byte-identified, but
   independent clean-build reproducibility has not been repeated for this
   candidate; cross-host reproducibility is not claimed.
4. **Python acceptance:** CPython 3.12 wheel/install and copied example pass,
   but full S-T10 (native layout probe, missing-library/errors, exact-clock,
   threading) remains incomplete.
5. **Rights/release:** vendor notices are preserved. The archive is a local
   candidate only; no independent legal review or publication clearance is
   claimed.
6. **Advanced capabilities:** LiveKit lacks pinned/tested host dependencies.
   Tiny16 evaluation rights/runtime parity are unknown. S11 engine ABI and
   installed fixture are absent. Additional formats, callback-safe mode 1 and
   shared execution-domain engines are not advertised.

Do not silently change a ready header/schema. Any contract change must update
the revision, digests, evidence and this handoff before dependent work proceeds.
