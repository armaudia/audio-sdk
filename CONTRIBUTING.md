# Contributing

Use a pull request, code-owner review, passing CI and squash merge. Public API
and integration files are Apache-2.0; core implementation and core tests are
MPL-2.0. Third-party files retain their original terms. See LICENSE.md.

Substantive external contributions require verified private acceptance of the
[individual CLA](CLA/individual.md) benefiting **Tsakanyan Hovhannes** personally.
Contributors retain copyright; accepted contributions remain available under
the applicable open-source license and may additionally be commercially licensed.
Read [the signing and approval process](CLA/README.md). CI requires an existing
maintainer-recorded approval; it does not fabricate or collect signatures.

Declare imported code, models, datasets, recordings and licensing exceptions.
Do not attach private audio, weights, secrets or inadequately licensed material.
An ICLA does not clear third-party rights. Licensing and imported-material
exceptions require a documented manual review before merge.
